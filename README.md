# 5-Epsilon Website

Public-facing static website for 5-Epsilon.

Open `index.html` in a browser to view the landing page. The contact page is available at `contact.html`.

## AWS Amplify

This repo is ready for Amplify static hosting. Connect the repository in AWS Amplify Hosting and use the included `amplify.yml` build settings. Amplify will publish the repository root as the static artifact directory.
